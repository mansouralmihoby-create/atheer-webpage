# 🎮 قالب تحدي الإنجليزية التفاعلي للبث المباشر (TikTok LIVE Overlay)

قالب ويب تفاعلي بنسبة طولية **9:16** (1080x1920) مصمم خصيصاً لبرامج البث مثل **OBS Studio** و **TikTok LIVE Studio** لإشعال التعليقات والتفاعل التلقائي في البث المباشر.

---

## ✨ المميزات الرئيسية

1. **دورة زمنية ذكية (Pacing Cycle)**:
   - **0 - 3 ثوانٍ**: عرض السؤال مع فراغ مشوق وترجمة عربية.
   - **3 - 8 ثوانٍ**: مؤقت دائري تنازلي (5 ثوانٍ) بصوت تكتكة ساعة واقعي يتسارع في آخر ثانيتين.
   - **8 - 12 ثانية**: إضاءة الإجابة الصحيحة باللون الأخضر المشع، مع صوت رنين النجاح (Ding!) وشرح "السر" لزيادة الفائدة.
   - **12 - 14 ثانية**: انتقال تلقائي وسلس للسؤال التالي مع صوت Whoosh.
2. **مؤثرات صوتية ذاتية (Web Audio API)**:
   - لا تعتمد على ملفات MP3 خارجية قد تفشل في التحميل؛ الأصوات يتم توليدها برمجياً فورياً وتعمل دون إنترنت.
3. **توزيع متقن للشاشة (Safe Zone)**:
   - المساحة السفلية (35-40%) متروكة فارغة أو شفافة حتى لا تغطي تعليقات وهدايا المتابعين الأسئلة والخيارات.
4. **أوضاع OBS و TikTok LIVE Studio**:
   - إمكانية تشغيل خلفية نيون داكنة أو جعلها شفافة تماماً لإظهار كاميرا المذيع أو خلفية متحركة خلف البطاقة.

## 🚀 كيفية التشغيل في برنامج البث (OBS / TikTok LIVE Studio)

### الطريقة 1: خادم محلي سريع (موصى به جداً)
افتح التيرمينال داخل مجلد المشروع وشغّل:
```bash
python3 -m http.server 8080
```

ثم داخل **OBS Studio** أو **TikTok LIVE Studio**:
1. أضف مصدراً جديداً من نوع **Browser Source** (متصفح).
2. في خانة الـ **URL** ضع الرابط التالي:
   ```text
   http://localhost:8080/?stream=1
   ```
3. اضبط الأبعاد إلى:
   - **العرض (Width)**: `1080`
   - **الارتفاع (Height)**: `1920`
4. فعّل خيار **Control audio via OBS** (التحكم بالصوت عبر OBS) إذا أردت بث صوت التكتكة والرنين للمشاهدين مباشرة.

## ⌨️ اختصارات لوحة المفاتيح للمتحكم (Hotkeys)

| الزر | الوظيفة |
| :--- | :--- |
| **مسافة (Space)** | إيقاف مؤقت / استئناف البث التلقائي |
| **سهم يمين أو N** | الانتقال للسؤال التالي فوراً |
| **سهم يسار أو P** | الرجوع للسؤال السابق |
| **حرف M** | كتم / تشغيل المؤثرات الصوتية |
| **حرف H** | إخفاء / إظهار شريط أزرار التحكم السفلي |
| **حرف T** | التبديل الفوري بين الخلفية الداكنة والخلفية الشفافة لـ OBS |

---

## ⚙️ معلمات الرابط (URL Parameters)

يمكنك تخصيص طريقة ظهور القالب في الـ Browser Source عبر إضافة هذه المتغيرات إلى نهاية الرابط:

- **إخفاء أزرار التحكم للبث**: `?stream=1`
- **جعل الخلفية شفافة تلقائياً**: `?bg=transparent`
- **دمج الاثنين معاً**:
  ```text
  http://localhost:8080/?stream=1&bg=transparent
  ```

## 📝 إضافة وتعديل الأسئلة

يمكنك إضافة مئات الجمل بسهولة داخل ملف [questions.json](file:///Users/mansour/.gemini/antigravity-ide/scratch/tiktok-quiz-overlay/questions.json):
```json
{
  "id": 13,
  "level": "مستوى 2: فخاخ شائعة 🔥",
  "levelClass": "trap",
  "sentence": "I agree ___ you 100%.",
  "blank": "___",
  "translation": "أنا أتفق معك بنسبة 100%",
  "options": [
    { "letter": "A", "text": "with" },
    { "letter": "B", "text": "to" },
    { "letter": "C", "text": "on" }
  ],
  "correctIndex": 0,
  "explanation": "نقول دائماً Agree with someone عند الاتفاق مع شخص."
}
```
الأصناف المتاحة للـ `levelClass`:
- `easy`: إحماء سهل (أزرق سماوي)
- `trap`: فخاخ وأخطاء شائعة (برتقالي ناري)
- `pro`: مصطلحات ومحترفين (بنفسجي ملكي)
